# 查找代理技能

1. 先看 [.codex/README.md](../../README.md) 中已经共享的技能。需要扩大查找范围时，按用户任务组织查询词，例如 `pnpm dlx skills find react accessibility`。
2. 推荐前阅读候选的 `SKILL.md`，核对来源仓库、许可证、外部工具和安装范围。给出符合任务的候选项及其来源链接。
3. 用户要求安装时，按其指定的来源和范围执行。纳入本仓库的技能放在 `.codex/skills/<name>/`，保留许可证及所需的配套文件，并更新技能索引。
